# Alkaline / legacy

A Minecraft 1.8.9 PvP client in development. Alkaline as a whole may target multiple versions, but **this `legacy/` repository is for 1.8.9 only**. This repository is not yet a complete client: multiplayer is **partially** playable: join a 1.8.9 server, walk around its world under vanilla's sky, clouds and weather, see players (with skins and name tags), nearly every mob with armor, held items and enchantment glint, and objects (minecarts, boats, paintings, item frames, armor stands, XP orbs, fireworks), attack them, dig blocks (vanilla break times, cracks and particles), hold maps, hear vanilla's sounds, read the HUD (health, hunger, hotbar, chat, scoreboard, titles), type in chat (history, Tab completion, clickable and hoverable messages) and module readouts, use the player inventory (2x2 crafting, armor, vanilla's click rules) and every window a server opens (chests and server menus, crafting tables, furnaces, brewing stands, enchanting tables, anvils, beacons, hoppers, dispensers, villagers, horses) plus the sign editor, right-click to use items, open blocks and place blocks (the server decides placement), throw and shoot projectiles, and switch to third person; movement, knockback, sprinting and sneaking follow vanilla's rules (its bugs included), potion effects show, the world border shows and blocks, and resource packs load (including a server's pack, with a remembered per-server choice), with OptiFine custom item textures, connected textures, custom sky and colors, random, emissive and animated entity textures; there is no creative inventory or music yet ([decision 0006](docs/decisions/0006-block-models-multiplayer-sky-and-input-fix.md), [decision 0007](docs/decisions/0007-hud-modules-profiles-entities-and-effects.md), [decision 0008](docs/decisions/0008-hud-cache-partial-blur-and-inventory.md), [decision 0011](docs/decisions/0011-protocol-coverage-windows-and-launcher.md), [decision 0012](docs/decisions/0012-pvp-parity-items-third-person-and-resource-packs.md), [decision 0013](docs/decisions/0013-mobs-glint-sound-and-chat.md), [decision 0014](docs/decisions/0014-objects-digging-server-packs-optifine-and-world.md)). Minecraft 1.8.9 uses protocol 47. Game rendering targets **Vulkan 1.3/1.4** (and requires 1.3 today), with **SDL3** window and input management. The in-game GUI/HUD is built with **Kotlin, Compose Multiplatform, and Material 3 Expressive** inside the renderer module; the developer-only Compose Desktop preview app is separate from production. The HUD is built from modules whose placement, scale and options live in named profiles (JSON files), edited in game with the ClickGUI and the HUD editor.

Read [AGENTS.md](AGENTS.md) before implementation. The project is deliberately aggressive and original: **think different**, high performance before compatibility, and borrow as little code and structure from other projects as possible. GTX 10 Series **and older** is the GPU ceiling (inclusive), not a minimum. Below that ceiling the floor is **Vulkan 1.1**, with no specific model floor, through a planned compatibility mode that is **not implemented yet** ([decision 0004](docs/decisions/0004-vulkan-1-1-compatibility-floor.md)); until it exists, devices need Vulkan 1.3.

These boundaries keep the platform, renderer, 1.8.9 game integration, settings, and UI separate without inventing a multiversion or universal plugin API.

The visible client runs with `./gradlew :apps:game-client:run`. It opens a resizable SDL3/Vulkan window and shows Alkaline's Material 3 Expressive title screen, rendered by Compose **inside the game**: an offscreen Compose scene on its own UI thread is uploaded to a Vulkan texture and composited over the scene, with GPU-blurred frosted glass behind its surfaces. Startup shows a loading screen while assets open off the render thread; it fades to the background, then the menu (logo and four actions) animates in. The background is the vanilla 1.8.9 panorama, loaded from your own `~/.minecraft/versions/1.8.9/1.8.9.jar` (or `ALKALINE_MINECRAFT_JAR`), the asset-free procedural "Blue Planet" scene (a crescent Earth, the Sun in frame, and a geostationary satellite modelled on photographs of an SSL 1300-class spacecraft), or "Overworld": generated terrain with vanilla block textures drawn by the GPU world renderer. A vanilla-style GUI scale (Auto picks the largest 25% step the window fits; larger choices are capped) sizes every screen. On Wayland desktops the client runs natively on Wayland (X11 is the fallback). The present mode is chosen automatically: with V-Sync off (the default) the game draws uncapped without tearing where the display allows it, and V-Sync, where the driver can wait for presentation, is paced to the display for one refresh less latency than plain FIFO ([decision 0009](docs/decisions/0009-frame-rate-cap-under-xwayland.md), [decision 0010](docs/decisions/0010-native-wayland-automatic-present-mode-and-paced-vsync.md)). Settings persist to `~/.alkaline/legacy/settings.json`, apply on the next frame, and say when a value needs a restart (the menu can relaunch the client). The default background is "Fluid", a port of the nice-elements fluid effect drawn in the theme's colors; moving the pointer stirs it. Themes are Material You ("Monet") Light and Dark, generated from Alkaline's seed color. The account button at the top left signs in with a Microsoft account in the system browser. Singleplayer lists your worlds from `.minecraft/saves`, with a map picture of each that has no icon, and plays or creates them on a local Paper 1.8.8 server that is downloaded on first use; the saves stay vanilla saves ([decision 0024](docs/decisions/0024-local-paper-server-pvp-modules-and-shared-skeletons.md)). Multiplayer pings your servers (seeded once from vanilla's `servers.dat`) and joins them: offline-mode servers work today; the Join path does not yet use the signed-in account for online mode. Singleplayer, Multiplayer and Settings grow out of their buttons and shrink back into them. Joining a server keeps the menu up under the joining card until the world around the player is meshed, then cross-fades into it. In game, Esc opens the pause card (resume, settings, modules, disconnect or save and quit), and Right Shift opens the ClickGUI: music (files, folders, streams, YouTube and SoundCloud through an installed yt-dlp, Spotify and Apple Music links; playlists; the media keys work everywhere), plugins (each with its details, settings and HUD elements; Reload picks up new jars) and modules (FPS, coordinates, CPS, keystrokes, ping, clock, speed, server, potion effects, notifications, scoreboard, chat, health and hunger, hotbar, zoom, and for PvP: reach display, combo counter, target HUD, armor status, item counter, freelook, hitboxes and the block outline) in the active profile, and the HUD editor, where elements drag and snap into place; each element with a surface has its own Blur option. E opens the inventory; the use key (right click) eats, drinks, draws the bow and blocks with the sword, opens chests and every other container, trades with villagers and places blocks ([decision 0011](docs/decisions/0011-protocol-coverage-windows-and-launcher.md)). F5 cycles first person, behind and in front. The Animations module adds 1.7-style block-hitting and moves or scales the held item; Toggle Sprint & Sneak latches either key. Settings → Resource packs layers packs from `~/.alkaline/legacy/resourcepacks` and Minecraft's `resourcepacks` folder over the vanilla assets and reloads them in game ([decision 0012](docs/decisions/0012-pvp-parity-items-third-person-and-resource-packs.md)). The launcher in [`../launcher`](../launcher) starts this client with one click. The HUD (and its blur) redraws at most at the HUD frame rate, the display's refresh rate by default, and frames in between reuse the cached HUD. Profiles live in `~/.alkaline/legacy/profiles/`. See [decision 0003](docs/decisions/0003-themes-fluid-accounts-and-servers.md), including the caveat that sign-in currently uses a borrowed public OAuth client id until Alkaline registers its own. See [decision 0002](docs/decisions/0002-menu-frame-ui-host-and-settings.md) for the design and measurements.

Diagnostics can probe the SDL surface, run a hidden indexed Vulkan mesh frame smoke, or open an interactive mesh preview with `./gradlew :apps:diagnostics:run --args=--frame-preview`. The preview is a presentation/lifecycle check, not Minecraft rendering or parity evidence. Open the separate HUD preview with `./gradlew :apps:hud-preview:run`; pass a profile file (from `~/.alkaline/legacy/profiles/`) to preview its HUD, add `--edit` to move elements with the HUD editor, or pass `--menu` for the title screen. Press F2 to save the preview window as PNG. The GPU world renderer draws vanilla block models, liquids and lighting from section meshes built on worker threads, for the Overworld menu background and for multiplayer worlds, with clouds, entities and particles in game. It has no biome colors and no same-frame parity evidence.

On Linux, libinput debounces mouse buttons, which drops fast butterfly and drag clicks in every application. Alkaline takes clicks from the window system as Minecraft does; `./gradlew :apps:diagnostics:run --args="--click-fix install"` installs libinput's `ModelBouncingKeys` quirk for mice through `pkexec` (log out and back in to apply; `remove` undoes it). A launcher button is planned.

## Setup

- **Java 25 JDK** for Java and Kotlin compilation and runtime; the checked-in Gradle 9.7.0 wrapper bootstraps the build. Gradle also needs a compatible JVM to run, and network access to download the distribution and pinned Maven artifacts.
- **Windows or Linux x86-64** plus a Vulkan 1.3-capable loader and physical-device driver for the game diagnostic. On Linux, a working GUI session (Wayland or X11) is needed; a headless CI environment can run unit tests and PNG comparisons but not a real SDL surface.
- Matching LWJGL 3.4.3 SDL/core native artifacts are provided by the diagnostic build. Use only the wrapper for ordinary builds; a system-installed SDL3 version does not replace pinned LWJGL natives.
- The read-only upstream checkout is deliberately Git-ignored. Recreate it when API inspection is needed: `git clone --branch 3.4.3 --depth 1 https://github.com/LWJGL/lwjgl3.git external/lwjgl3` (expected commit `30fac9b95f99cda97312232be25ba55297bf9951`). It is not necessary for building Alkaline.
- Shader changes: edit the GLSL beside the packaged resources; any build regenerates the SPIR-V (`processResources` depends on `packageVulkanShaders`, which needs `glslc` and otherwise warns and keeps the checked-in binaries). `verifyVulkanShaders` requires `spirv-val`.
- Kotlin 2.4.21 and Compose Multiplatform 1.12.1 provide the in-game Compose API. Material 3 `1.13.0-alpha02` is a deliberate prerelease exception for its Expressive APIs. Plugins are jars in `~/.alkaline/legacy/plugins/` with an `alkaline-plugin.json` manifest; they run in the client's process with the player's own access to the computer and are unrestricted, and Alkaline's future plugin market is where listed plugins will be reviewed ([decision 0022](docs/decisions/0022-unrestricted-plugin-api-and-manifest.md), [docs/plugins](docs/plugins/README.md)). A plugin's failures, an interface crash included, stop only that plugin ([decision 0023](docs/decisions/0023-plugin-hardening-and-music-player.md)).
- The music player decodes with FFmpeg 8.1.2 (LGPL build) through JavaCPP 1.5.14, whose natives for Linux and Windows x86-64 come with the build. YouTube, SoundCloud and other sites, and the audio for Spotify and Apple Music links (their own audio is DRM-protected), need [yt-dlp](https://github.com/yt-dlp/yt-dlp#installation) on the `PATH` (or in `~/.alkaline/legacy/tools/`), plus Deno or Node.js for YouTube; streaming those sites outside their own players is against their terms. Music files live in `~/.alkaline/legacy/music/`.

```bash
cd legacy
./gradlew check
./gradlew :apps:diagnostics:run
./gradlew :apps:diagnostics:run --args=--frame-smoke
./gradlew :apps:diagnostics:run --args=--frame-preview
./gradlew :apps:game-client:run
./gradlew :apps:game-client:run --args="--stats"
./gradlew :apps:game-client:run --args="--screenshot /tmp/menu.png --after-ms 4000 --page settings"
./gradlew :apps:hud-preview:run
./gradlew :apps:hud-preview:run --args=--menu
./gradlew :apps:hud-preview:run --args="/path/to/profile.json --edit"
```

The screenshot shortcut (`F2`) opens a save dialog. Choose a `.png` destination to capture the preview window.

- The repository is not yet a complete client (see the multiplayer limits above). It has a dedicated 20 Hz snapshot tick loop and bounded asynchronous CPU scene compilation, plus the Vulkan 1.3 indexed-mesh frame smoke path and CPU-side image, font, section-mesh, and textured scene submission foundations. It now also has a Vulkan frame encoder with depth and per-frame streaming, GPU-instanced model and particle renderers drawing the server's entities and particles, and an in-game Compose host with the HUD. It still has no block breaking, no singleplayer, and no automatic deterministic capture producer. The in-game Compose host rasterizes with Skia on the CPU and uploads to Vulkan; it is not a Skia-on-Vulkan backend. `apps:hud-preview` is a separate Compose Desktop design preview, not evidence of in-game rendering. No target-era GPU/Windows compatibility or visual-parity claim is made.

## Screen-space consistency check

Supply the original OpenGL reference and Vulkan candidate as separate PNG captures of the **same frame**. The checker compares every decoded 8-bit RGBA value at the same coordinates, with **zero tolerance**, and writes a same-size PNG mask: gray (`#404040`) for identical pixels, magenta (`#FF20C0`) for any difference, including alpha. It does not resize, align, flip, or mask images. The output is always opaque so even hidden RGB/alpha differences remain visible.

Run from `legacy/`, substituting real capture paths and a **new** result path in an existing directory:

```bash
./gradlew :apps:screen-space-check:run --args="--opengl /path/original-gl.png --vulkan /path/alkaline-vk.png --output /path/result.png"
```

For scripts that need the exact exit code, use the installed executable (Gradle itself reports a task failure for any nonzero program exit):

```bash
./gradlew :apps:screen-space-check:installDist
apps/screen-space-check/build/install/screen-space-check/bin/screen-space-check \
  --opengl /path/original-gl.png --vulkan /path/alkaline-vk.png --output /path/result.png
```

On Windows, use `gradlew.bat` and the generated `screen-space-check.bat`. Arguments use the order shown; quote paths containing spaces. Exit **0** means exact match, **1** means differing pixels (the result PNG is still written), and **2** means input/usage/output failure. Existing output files and self-comparison are rejected. Inputs must be valid, complete, non-animated PNGs of equal dimensions, at most 16,777,216 pixels and 128 MiB per file. Greater-than-8-bit PNGs are rejected to avoid silently discarding precision.

The original OpenGL image is the expected result. Once the capture contract is satisfied, any mismatch is a Vulkan regression to investigate. Match resolution, viewport, camera/FOV, tick and interpolation, world/entity state, assets, lighting, shader settings, GUI scale, dithering, antialiasing, sRGB/color space, and alpha semantics. Normalize OpenGL's bottom-up readback to the same top-left origin as the Vulkan PNG **when capturing**. Resolve multisampling before export; disable animated/nondeterministic elements. PNG compression bytes/metadata are not compared. The decoded pixels use Java's 8-bit default RGB/straight-alpha representation; provide captures in the same color encoding and do not expect the checker to diagnose color-management differences.

**Automatic capture hooks and actual 1.8.9 game rendering are not implemented.** This is a working file comparison tool, not proof that a Minecraft Vulkan pipeline already matches OpenGL. No GPU or display is needed to compare supplied captures.

Finish multiplayer: name tags, objects (minecarts, boats...) and emissive mob layers (dragon and enderman eyes, wither armor), ender chests, skulls, banners and other tile entities (in the world and in hand), block breaking, the creative inventory and books, client relighting, the death screen, music and the remaining client-side sounds (rain, lightning, minecarts) and the Music section, biome colors, and online-mode sign-in on the Join path.
